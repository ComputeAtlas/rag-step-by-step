# Parts Catalogue: Displays, Motors, Controllers and Sensors

Prices in pounds, including VAT, from 1 January 2026. Motors and controllers are covered by the warranty for 2 years
(see the warranty policy for your year of purchase). Fitting a motor or controller should be done by a Fernhill dealer.

Notes:

- The Dash 1 and Dash 2 are not interchangeable. Dash 1 has no walk-assist button; the Metro 300 starts walk assist by
  holding the minus button.
- If the display shows E20 (display memory fault) the display must be replaced. After fitting, update the firmware on
  both display and controller to the same version.

Torque sensors are built into the Ridge 500 and Cargo 700 motors and are not sold separately. The Metro 300 hub motor
has its speed sensor built in, which is why error E04 on that model cannot be fixed at home.

## Which error code points to which part?

| Error | Model | Part to suspect |
|---|---|---|
| E03 | Metro 300 | Cadence sensor FH-6291-A |
| E04 | Ridge 500, Cargo 700 | Speed sensor FH-6290-A, or the magnet gap (3 to 5 mm) |
| E04 | Metro 300 | Hub motor FH-6108-A (sensor built in) |
| E11 | All | Brake lever with cut-off switch (FH-3310-A or FH-3311-A) |
| E12 | Ridge 500, Cargo 700 | Shift-assist sensor FH-6295-A |
| E19 | All | Motor, after a dealer check |
| E20 | Metro 300 | Display FH-5101-A |
| E20 | Ridge 500, Cargo 700 | Display FH-5102-A |

Always follow the fix in the owner's manual before ordering a part.
